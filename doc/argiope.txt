1. Introduction                                                *argiope*

Argiope adds Tree-sitter highlighting and indentation for HTML, CSS, Markdown,
and JavaScript inside JavaScript tagged template literals. Substitutions remain
owned by the host JavaScript tree.

Bare tags and the final property of member-expression tags are supported:
>
    const page = html`<main>${content}</main>`
    const notes = ui.md`## ${title}`
<
Argiope does not define pairing, surround, or insert-mode mappings. It adds
HTML-aware normal and Visual mode J mappings when J is otherwise unmapped.

==============================================================================
2. Requirements                                    *argiope-requirements*

- Neovim 0.12 or newer
- neovim-treesitter/nvim-treesitter
- neovim-treesitter/treesitter-parser-registry
- JavaScript, HTML, CSS, Markdown, and Markdown-inline parsers and queries
- ECMA, JSX, and HTML-tags inherited query packages

Only the "javascript" filetype is supported in the first release.

==============================================================================
3. Installation                                    *argiope-installation*

Install the parser registry first, then nvim-treesitter and Argiope:
>
    vim.pack.add({
      {
        src = "https://github.com/neovim-treesitter/"
          .. "treesitter-parser-registry",
      },
      {
        src = "https://github.com/neovim-treesitter/nvim-treesitter",
      },
      {
        src = "https://github.com/m4r-sh/argiope.nvim",
        version = vim.version.range("0.1"),
      },
    }, {
      load = true,
    })

    require("argiope").setup()
<
Install the required parsers once:
>
    require("nvim-treesitter").install({
      "javascript",
      "html",
      "css",
      "markdown",
      "markdown_inline",
      "ecma",
      "jsx",
      "html_tags",
    }):wait(300000)
<
See |vim.pack| and the nvim-treesitter documentation for update management.

4. Configuration                                           *argiope-setup*

Calling setup() is optional. The complete defaults are:
>
    require("argiope").setup({
      enabled = true,
      filetypes = {
        javascript = true,
      },
      tags = {
        css = "css",
        html = "html",
        md = "markdown",
        ["raw.js"] = "javascript",
      },
      indent = {
        enabled = true,
        shiftwidth = 2,
        expandtab = true,
      },
      highlight = {
        enabled = true,
      },
      join = {
        enabled = true,
      },
      theme = {
        variant = "classic",
      },
      palettes = {
        css = "green",
        html = "cyan",
        javascript = "gold2",
        javascript_embedded = "gray",
        markdown = "blush",
      },
    })
<
                                                     *argiope-config-enabled*
enabled ~
    Enables or disables all Argiope buffer behavior.

                                                   *argiope-config-filetypes*
filetypes ~
    Maps supported Neovim filetypes to booleans. Only JavaScript is currently
    supported.

                                                        *argiope-config-tags*
tags ~
    Maps tag spellings to "html", "css", "javascript", or "markdown". A name
    may be an exact member expression such as the default "raw.js". Bare names
    also match the final property of a member expression.

                                                      *argiope-config-indent*
indent.enabled ~
    Enables Argiope's buffer-local indent expression.

indent.shiftwidth ~
    Sets the indentation width. Zero uses the buffer's existing 'shiftwidth',
    falling back to 'tabstop'.

indent.expandtab ~
    Sets the buffer-local 'expandtab' option while Argiope is attached.

                                                   *argiope-config-highlight*
highlight.enabled ~
    Enables JavaScript and embedded-language Tree-sitter highlighting.

                                                        *argiope-config-join*
join.enabled ~
    Enables the context-aware buffer-local J mapping when J is otherwise
    unmapped.

                                                       *argiope-config-theme*
theme.variant ~
    Selects a palette interpretation while preserving all language-to-family
    assignments. Values are "classic", "contrast", "quiet", and "day".

                                                    *argiope-config-palettes*
palettes ~
    Selects colors used by the bundled colorscheme. Available names are:
    gold, beige, gold2, gray, blue, indigo, violet, blush, ember, slate, pink,
    green, cyan.
    "javascript" controls host JavaScript; "javascript_embedded" independently
    controls JavaScript inside tags such as raw.js.

setup() may be called again. Argiope refreshes its tag registry, autocmds,
theme (when active), and loaded supported buffers.

5. Indentation                                            *argiope-indent*

Use normal Neovim indentation commands such as "gg=G" or "=ip".

Argiope indents template content relative to its tag, uses embedded HTML and
CSS indent queries for nested structure, adds depth inside multiline
substitutions, and aligns a closing backtick with the tag line. The prior
JavaScript indent expression is retained outside tagged templates.
Unregistered tags such as "txt" receive the generic flat template baseline.

Without the nvim-treesitter indent engine, embedded content uses a flat
template baseline.

Inside registered HTML templates, normal or Visual mode J removes whitespace
between an opening tag and its content and between content and a closing tag:
>
    <div class=${BTN.LABEL}>${label}</div>
<
Ordinary prose keeps the normal joining space, and J is unchanged outside HTML
templates. Argiope does not replace an existing J mapping. Set
"join.enabled = false" to disable the buffer-local mapping.

6. Comments                                           *argiope-comments*

Neovim's built-in "gc" operator uses a comment string based on the registered
template language. HTML and Markdown use <!-- -->, CSS uses /* */, and
embedded JavaScript uses //.

For a language-neutral comment that remains valid inside any JavaScript
template literal, map toggle_interpolation_selection() in Visual mode:
>
    vim.keymap.set("x", "<leader>zc", function()
      require("argiope").toggle_interpolation_selection(0)
    end, {
      desc = "Toggle template interpolation comment",
    })
<
Characterwise selections wrap the exact range and may occupy part of one line
or span multiple lines. Visual Line selections wrap each selected nonblank
line. Selecting exactly the inside or outside of ${value} changes it to
${''/* value */} without nesting another interpolation.

7. Colorscheme                                             *argiope-theme*

Argiope's editing behavior works with any colorscheme. Enable the bundled
theme with:
>
    colorscheme argiope
<
HTML, CSS, Markdown, host JavaScript, and embedded JavaScript each use a
configurable hue family. Embedded JavaScript is gray by default. The original
profile and three additive cusphanger-generated interpretations reuse those
assignments:

    classic     original palette, unchanged (default)
    contrast    wider lightness range and stronger chroma
    quiet       neutral syntax with chromatic structure and keywords
    day         reversed emphasis on a light background

Select one in setup with theme = { variant = "quiet" }, or switch live with:
>
    :ArgiopeThemeVariant day
<
The equivalent Lua API is require("argiope").get_theme_variant() /
require("argiope").set_theme_variant("day").

The default "monochrome" mode applies those palettes to all four languages.
The "hybrid" mode keeps embedded HTML, CSS, and Markdown monochrome while
using the active profile's multicolored semantic JavaScript syntax.

Toggle between the modes with:
>
    :ArgiopeThemeToggle
<
For example, map the Lua method to <leader>zt:
>
    vim.keymap.set("n", "<leader>zt", require("argiope").toggle_theme, {
      desc = "Toggle Argiope JavaScript colors",
    })
<
The equivalent Lua API is:
>
    require("argiope").get_theme_mode()
    require("argiope").set_theme_mode("hybrid")
    require("argiope").set_theme_mode("monochrome")
    require("argiope").toggle_theme()
<
The mode persists when the Argiope colorscheme is reapplied.

Argiope's structural HTML language tree does not run child injections. A
normalized pass safely highlights literal JavaScript in <script> elements and
CSS in <style> elements without recursing through JavaScript substitutions.

8. HTML rendering                                      *argiope-render-html*

Argiope can render JavaScript source to a compact HTML code block on a server
that runs Neovim and has Argiope's parser requirements installed:
>
    local rendered = require("argiope.render").render(source)
    -- rendered.html is a <pre class="a j"><code>...</code></pre> block.
    -- rendered.css is the stylesheet to include once per page.
<
Use render.html(source) or render.css() when the two outputs are sent by
different layers. The renderer uses the same Tree-sitter language aliases,
highlight queries, and normalization passes as the editing integration; no
browser-side parser or highlighter is required.

Markup is intentionally terse. Family wrappers are j (host JavaScript), e
(embedded JavaScript), h (HTML), c (CSS), and m (Markdown); l0 through l11
are the shared Argiope shade ladder. The stylesheet scopes chromatic and
neutral hue variables as --a-h and --a-gh on each family. A client can shift a
family's hue by overriding those variables without changing HTML.

Each code-block pre element also has a readable language class, for example
lang-javascript, lang-lua, or lang-json. Its --a-bg variable controls the
whole code-card background, allowing page CSS to theme syntax-specific cards.

Rendering targets the bundled monochrome Argiope theme. Pass mode = "hybrid"
to use the same host-JavaScript colors as :ArgiopeThemeToggle:
>
    require("argiope.render").html(source, { mode = "hybrid" })
<
Hybrid output uses semantic g0 through g11 classes because its colors cannot be
recovered from the monochrome shade level alone. Rendering preserves source
whitespace and indentation exactly.

Pass an installed Tree-sitter parser language to use Neovim's ordinary
highlight and injection pipeline for another syntax:
>
    local html = require("argiope.render").html(source, { language = "html" })
    local lua = require("argiope.render").html(source, { language = "lua" })
<
These renderings use compact g0 through g11 classes for the bundled editor
theme's semantic colours. Query-driven child injections are included when the
corresponding parser and query are installed. JavaScript remains specialized:
it uses Argiope's tagged-template families and normalization passes.

9. Health                                                 *argiope-health*

Run:
>
    :checkhealth argiope
<
The check reports Neovim compatibility, required parsers and queries, and the
nvim-treesitter indent engine.

==============================================================================
10. Limitations                                      *argiope-limitations*

- Only JavaScript buffers are supported.
- Embedded languages are HTML, CSS, Markdown, and JavaScript.
- Pairing, surrounds, insert-mode mappings, LSP integration, completion, and
  formatting are outside Argiope's scope.
- Live indentation of incomplete embedded structures can fall back to the
  generic template baseline until Tree-sitter can parse the structure.
